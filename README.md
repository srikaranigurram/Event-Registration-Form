# Event Registration Form

A modern and responsive **Event Registration System** built using HTML, CSS, and JavaScript. The project provides user registration, login authentication, and a personalized event dashboard.

## Features

* User Sign Up
* User Sign In
* Client-side form validation
* Password visibility toggle
* Local Storage-based user authentication
* Personalized user dashboard
* Event details and registration status
* Logout functionality
* Responsive design
* Glassmorphism UI
* Modern animated interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Project Structure

```text
Event-Registration-Form/

├── index.html        # Sign In page
```

## Application Flow

```text
Sign Up
   ↓
Create Account
   ↓
Sign In
   ↓
Authentication
   ↓
Dashboard
   ↓
View Event Details
   ↓
Logout
```

## Dashboard

After successful login, the user is redirected to the dashboard where they can view:

* Participant name
* Registered email
* Registration status
* Event name
* Event date
* Event time
* Event venue
* Entry information

## How to Run

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `signup.html` using Live Server.
4. Create a new account.
5. Sign in using the registered credentials.
6. The dashboard will open after successful authentication.

## Data Storage

This project uses the browser's **Local Storage** to store registration information and maintain the login session.

> Note: This is a frontend demonstration project. It does not use a backend database or server-side authentication.
