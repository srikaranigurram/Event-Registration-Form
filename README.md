# Event Registration Form

A responsive Event Registration web application featuring modern Sign Up and Sign In pages.

## Features

- User Registration
- User Login
- Local Storage Authentication
- Password Visibility Toggle
- Responsive UI
- Glassmorphism Design
- Form Validation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Folder Structure

Event-Registration-Form/
│── index.html
│── signup.html
│── style.css
│── script.js
└── README.md

## How to Run

1. Download or Clone the repository.
2. Open `signup.html` in your browser.
3. Create an account.
4. Login using the registered credentials.
